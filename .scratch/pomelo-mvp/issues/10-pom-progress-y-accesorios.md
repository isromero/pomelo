# Pom, Progress y accesorios

Status: ready-for-agent

## Parent

[PRD: Pomelo MVP](../PRD.md)

## User stories

55 y 91-96.

## What to build

Convertir a Pom en la recompensa compartida del lifecycle real. Reveal debe producir una reacción breve, las Memories deben avanzar Progress y desbloquear un conjunto pequeño de expresiones o accesorios seleccionables, sin introducir necesidades, castigo o economía virtual.

## Acceptance criteria

- [ ] Reveal reproduce una de aproximadamente tres reacciones breves de Pom sin bloquear el acceso al resultado.
- [ ] Crear una Memory incrementa Progress una sola vez aunque Reveal o sus eventos se reintenten.
- [ ] Progress pertenece a la Pair y se deriva de hitos comprensibles basados principalmente en Memories.
- [ ] El MVP soporta una etapa física, aproximadamente seis expresiones y aproximadamente cuatro accesorios desbloqueables.
- [ ] Existe una superficie sencilla para consultar y seleccionar accesorios ya desbloqueados.
- [ ] Home refleja el estado y accesorio actuales de Pom mediante el asset `Pom / Original` aprobado como referencia.
- [ ] Los assets temporales pueden sustituirse por el arte final de la diseñadora sin cambiar el modelo de Progress ni rehacer las pantallas.
- [ ] Inactividad, pérdida de Streak, Archive Mode o cierre del paywall nunca muestran hambre, enfermedad, muerte, tristeza o culpa.
- [ ] No existen monedas, tienda, habitación, minijuegos, múltiples mascotas ni micropagos cosméticos.
- [ ] Pruebas de comportamiento verifican idempotencia de Progress, desbloqueos, selección y ausencia de estados punitivos.
